Questions
Common questions
Do I need to already know how to code?▾
No — this is a starting qualification. You'll write your first working program in the first few weeks, no prior experience assumed.
What's the difference between this and Software Engineering?▾
Software Development focuses on building features and applications. Software Engineering (the next step) is a longer, broader qualification covering how whole systems are designed and maintained at scale.
Which programming languages will I actually learn?▾
Python first for fundamentals, then JavaScript for building things that run in a browser — the two most in-demand languages in the SA job market.
What if I only passed Grade 11, not Grade 12?▾
The standard entry requirement is NQF Level 4 (Grade 12) — but CTU offers an alternative entry route via a bridging course if you only completed Grade 11. Ask a facilitator today for details.
