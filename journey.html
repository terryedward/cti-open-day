Package it with Docker

Before your app goes anywhere, it's packaged into a container — the exact same environment whether it runs on a laptop, a server, or any cloud in the world.

terminal
$ docker build -t campus-app .

Pick where it runs

CTU teaches all three major clouds — because different employers standardise on different ones. Pick one to deploy to.

Azure

Microsoft's cloud — deeply integrated with Microsoft 365 and enterprise Windows environments. Common in SA banks and government.

AWS

The largest cloud provider globally — the industry default for scale, with a real data centre region in Cape Town.

Google Cloud

Strong in data and AI workloads — the same infrastructure that runs Google Search and YouTube.

Lock it down

A public app with no rules is an open door. Configure exactly what's allowed in.

Allow HTTPS (443)Encrypted traffic only — this is how the padlock in a browser gets there.
Restrict admin accessOnly CTU's own admin IP can manage the server directly.
Block everything elseDeny all other inbound traffic by default — the golden rule of cloud security.

Make it smart

📚 Skill taught: Supervised Model Training
Let's teach your app a trick. Tag each message Urgent or Normal — this is exactly how an AI feature actually gets trained.

"My order hasn't arrived and I'm late for class!!"

"Do you have vegetarian options?"

"The app crashed and I lost my payment!"

"What time do you open tomorrow?"

MODEL TRAINED

Your app can now auto-flag messages like these as urgent 🚨 — no human has to read every single one first. This is literally the AI Software Developer's job: real examples, tagged by people, turned into an automatic decision.
